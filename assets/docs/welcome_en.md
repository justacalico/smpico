### Hi! This is EZPico

An app that installs games and apps on PICO headsets from your PC. A few important things before you start.

#### Which internet resources it uses

- **GitHub** (`raw.githubusercontent.com`) — the PicoLand game catalog and covers;
- **Yandex Disk, Google Drive, SberDisk** — game downloads from catalog links (only when you press "Download");
- **Telegram** — only if you sign in yourself: downloads from PicoLand channels;
- **YouTube and your browser** — only when you open trailers and links.

EZPico has **no** own server, ads, analytics or telemetry.

#### What data it stores

Everything stays **on this PC only**: settings (registry, `HKCU\Software\EZPico`), install history, save backups, screenshots, recordings and reports (`C:\ProgramData\ezpico_workspace`). A problem report is created only by your button and is never sent automatically.

#### Telegram sign-in

Optional. Needed only for games stored in Telegram. Sign-in is by QR code, no phone number. By default the session lives in memory and ends when the app closes. With "Remember me" it is stored encrypted and can be decrypted only from your Windows account.

#### Tooltips and help

- Hover over a button or icon to see what it does.
- The full guide is in **Settings → Help and reset → Guide** (book icon).
